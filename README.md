# Savdochi — Next.js demo

## Ishga tushirish
1. Node.js 20+ o‘rnating.
2. Terminalda loyiha papkasiga kiring.
3. `npm install`
4. `npm run dev`
5. `http://localhost:3000` manzilini oching.

## Sahifalar
- `/` — bosh sahifa va storefront
- `/catalog` — katalog
- `/suppliers` — yetkazib beruvchilar
- `/offers` — takliflar
- `/about` — biz haqimizda
- `/login` — alohida kirish sahifasi
- `/register` — alohida registratsiya sahifasi
- `/dashboard` — demo boshqaruv paneli

## Muhim
Bu frontend prototip. Katalog, qidiruv, filtr, savatcha va demo buyurtma funksiyalari brauzerda ishlaydi. Login/registratsiya hozircha `localStorage` orqali demo tarzda ishlaydi; haqiqiy mahsulot uchun parollarni brauzerda saqlamasdan, Express API, MongoDB, parol hashing va server session/JWT bilan almashtirish kerak. Demo hisoblar boshqa qurilmalarda mavjud bo‘lmaydi.
